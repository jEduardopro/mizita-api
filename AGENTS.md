# AGENTS.md

This file is the cross-tool entry point for AI coding agents (Cursor, Copilot, Codex and others that look for `AGENTS.md`). It is not a list of agents.

**The conventions for this repository live in [`CLAUDE.md`](./CLAUDE.md).** Read that file before making changes: it documents the layered DDD structure under `app/Domains/`, the layer dependency rules, the uuid/int identity convention, the `make:domain` generator, and the PHP binary this project needs.

Everything in `CLAUDE.md` applies regardless of which tool you are.
